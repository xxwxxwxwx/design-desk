# 版式与信息层级规则

## 标准画布骨架

以 1080×1440 px 为唯一成品规格：

| 区域 | 建议范围 | 用途 |
|---|---:|---|
| 顶部预留区 | 0–160 px | 后期叠加饭团与商家联名信息 |
| 主标题区 | 170–450 px | 活动主题、招募人数、品鉴官或体验官 |
| 产品主视觉区 | 430–1000 px | 真实菜品、饮品和必要场景 |
| 活动信息区 | 990–1320 px | 人数、时间、地址、额度、规则 |
| 底部预留区 | 1320–1440 px | 后期叠加饭团固定搜索横条 |

区域可以适度交叠，但重要内容不得进入上下预留区。左右安全距离至少 60 px。

## 阅读顺序

默认阅读动线：商家或活动身份 → 招募主题 → 真实产品与福利 → 活动详情 → 后期叠加的饭团入口。

单商家海报优先级：

1. 招募人数与“品鉴官／体验官”。
2. 商家或产品主题。
3. 体验内容、额度或福利。
4. 时间、地址和报名规则。

多商家活动优先级：

1. 整体活动主题。
2. 各商家名称。
3. 每家招募人数与体验内容。
4. 总人数、总时间、地址和报名规则。

不要强制所有海报都把招募人数做成最大标题。单商家通常突出人数；多商家活动通常先突出总活动主题。

## 根据素材数量选择版式

| 输入情况 | 默认版式 |
|---|---|
| 单商家、1–3 个产品 | 中央大产品场景，一主两辅或均衡三角构图 |
| 2 款套餐或 2 个主推品 | 左右并列，使用相同标签结构 |
| 3 个商家 | 上二下一或错落卡片，每张卡保持相同字段 |
| 3 道并列产品 | 一主两辅、三角构图或三卡布局，不随机堆叠 |
| 4 款菜品 | 2×2 等尺寸矩阵 |
| 1 个主产品与辅助照片 | 主产品约占产品区三分之二，辅助照片做小卡片 |
| 产品多、文字少 | 放大真实产品和场景，保留呼吸感 |
| 规则或地址多 | 扩大底部信息卡，减少装饰，不缩小到难以阅读 |

## 信息密度

信息少时，放大真实产品、增加与商家相关的场景氛围和留白；不要虚构卖点填满画面。

信息多时，优先减少装饰和背景细节，将事实拆成图标、标签、行或卡片。长地址独占一行；报名规则超过两行时扩大信息区，而不是无限缩小字号。

## 视觉适配

- 商家现有品牌与产品气质决定主视觉。餐饮突出食欲、份量和套餐关系；饮品突出口味、季节和材质感。
- 可借鉴风格参考中的配色、纸张、光影、建筑线稿、笔刷和版面节奏，但不得复制未请求的价格、饮料、菜品或促销文案。
- 标题通常控制在 1–2 个视觉层级、最多 2–3 行；人数数字可以成为唯一强调色。
- 同一画面最多采用两套主要字体风格。标题可以有主题感，活动信息必须清晰易读。
- 多产品必须形成明确阵列，盘碗不能拉伸，产品不得顶住标题或安全区。
