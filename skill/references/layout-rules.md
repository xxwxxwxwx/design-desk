# v5.2 版式规则

## 中央创意

- 图片模型先生成一张完整的 8:9 中央创意。
- API 结果归一为 1080×1215。
- 顶部与底部各 30 px 只能包含可连续延展的环境背景。
- 裁去缓冲后得到 1080×1155，并原比例放入最终画布的 `x=0–1079, y=160–1314`。
- 所有标题、产品、活动事实、信息框、装饰及其阴影必须位于中央内容中。
- 活动时间、完整地址和完整报名规则必须位于同一个三行信息框内。

## 背景扩展

- 第二次生成只填充最终画布顶部 160 px 和底部 125 px。
- 必须延续中央图的材质、颜色、透视、光线、空间和氛围。
- 不得新增文字、数字、产品、包装、人物、徽章、信息卡、Logo 或口号。
- 不得出现接缝、色带、亮度跳变、镜像纹理、复制边缘、白边或框体。

## 品牌合成

饭团 Logo、商家 Logo、顶部联名面板、底部信息条和商家名称都由本地程序确定性合成，不发送给图片模型重绘。
