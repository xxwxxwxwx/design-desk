# 饭团小红书招募海报工作台

一个本地运行的饭团小红书招募海报生成工具。用户上传真实产品素材、商家 Logo 并填写活动信息后，工作台通过 KIE 生成主视觉，再在本地确定性合成饭团联名信息条，输出 1080 × 1440 PNG。

## 当前版本功能

### 素材与活动信息

- 支持上传 1–9 张 JPG、PNG 或 WebP 图片。
- 每张图片可标记为真实产品、商家参考、风格参考、版式参考、吉祥物 / IP 或其他素材。
- 支持单独上传商家 Logo，不占 9 张主素材限额。
- 可录入商家名称、招募类型、主标题、人数、时间、地址、体验内容、报名条件、报名方式和通知说明。
- 支持视觉方向、画面重点和补充说明。
- 不确定的信息可留空，不应自动虚构业务事实。

### AI 主视觉生成

- 当前通过 KIE API 调用 `gpt-image-2-5-sunburst-image-to-image`。
- 生成流程包含 Key / 积分检查、图片上传、异步任务创建、轮询、结果下载和本地合成。
- 生成前需由用户确认可能产生费用。
- API Key 默认只保存在当前服务进程内存中，不写入浏览器存储、任务记录或磁盘。

### 饭团信息条合成

- 支持“饭团＋商家联名”和“仅饭团”两种顶部模式。
- 顶部白色联名条由商家 Logo 的实际内容宽度驱动，整体自动居中。
- 自动裁去 Logo 透明边和近白色外围画布，保持原始比例，不拉伸。
- 根据方形、竖版、横版和超宽 Logo 分档控制最大视觉尺寸。
- 当前联名条参数：148 px 面板高度、36 px 底部圆角、42 px 左右 Padding、20 px 品牌间距。
- 底部饭团搜索信息条和商家名称由本地模板固定合成，不交给生成模型重画。

### 输出与验证

- 每次请求保存在 `data/jobs/<job-id>/`，不覆盖历史输出。
- 最终产物为 1080 × 1440 PNG。
- 附带尺寸与固定模板像素验证脚本。
- 技术验证通过仅代表尺寸和固定像素正确，不等于真实视觉验收通过。

## 本地启动

macOS 可直接双击：

```text
启动饭团小红书海报工作台.command
```

或者手动运行：

```bash
python3 -m pip install -r requirements.txt
python3 server.py
```

启动后访问 [http://127.0.0.1:8788](http://127.0.0.1:8788)，点击右上角“待配置 API Key”填写 KIE API Key。

## 项目结构

```text
app/static/                 前端表单与预览交互
data/jobs/                  本地生成任务（Git 默认忽略）
skill/assets/               饭团固定模板、字体与参考素材
skill/scripts/              海报合成与输出验证
server.py                   本地 API、KIE 调用与任务管理
```

## 当前已知限制

- AI 生成的主标题仍可能进入顶部 160 px 安全区，被联名条遮挡。
- 底部报名信息仍可能进入固定底栏区域。
- 产品名称需进一步清理上传文件的 `.jpg` / `.png` 扩展名。
- 低清小尺寸 Logo 放大时可能变糊，后续需增加放大倍率限制。
- 上下安全区自动视觉拦截仍未实现。

## 安全与版本边界

- `.env`、任务图片、生成结果和缓存均已从 Git 中排除。
- 不要将真实 API Key 提交到仓库。
- 重新调用付费模型前，应明确模型、生成数量与预计费用并获得确认。
