# 饭团小红书海报工作台 v1.3.0

本地运行的饭团小红书海报生成工具。工作台通过 KIE 完成中央创意与上下背景扩展，再在本地确定性合成饭团品牌信息条，输出一张 1080 × 1440 PNG。

## 版本矩阵

| 层级 / 模块 | 当前版本 | 状态 |
| --- | --- | --- |
| 整体工作台 | **1.3.0** | 当前发布版本 |
| 标准招募 | **5.2.0** | 正式可用；Prompt v5.2 与既有业务合同保持不变 |
| 自由创作 | **1.0.0** | 正式可用；包含 AI 自由创意与视觉参考创作 |
| 尺寸适配 | **0.0.0-unreleased** | 仅界面占位，尚未开发或开放 |

标准招募与自由创作共享中央创意生成、上下背景扩展、品牌 Logo 确定性合成和最终 3:4 输出能力；两者使用独立的业务字段校验和中央创意 Prompt。钉钉业务 API 入口保持独立。

## v1.3.0 主要更新

- 新增自由创作 1.0.0，工作台顶部可在标准招募、自由创作和尺寸适配占位之间切换。
- 自由创作支持“AI 自由创意”和“视觉参考创作”，不包含日期、地点、人数、报名规则、福利等标准招募结构化字段。
- AI 自由创意具备独立商业美术指导：即使没有视觉参考图，也会主动建立创意概念、色彩关系、背景环境、光影、材质、空间和字体节奏。
- AI 自由创意允许纯文字生成；上传图片时全部固定为真实产品素材。视觉参考创作保留逐图角色选择，并要求至少一张风格参考图。
- PRODUCT 图片以真实产品外观为第一依据，同时可提供配色、光影、材质和氛围等次级灵感；不会自动继承背景版式、文字、Logo、价格或促销信息。
- 主标题和可选副标题保留原文；商家名称默认只用于品牌识别和底部信息条，不在创意区擅自重复。
- 新增前后端角色校验、旧后端保护和 10 分钟单阶段生成等待上限；付费调用次数仍为每张海报 2 次。
- 标准招募 v5.2、品牌 SVG 合成、上下扩图策略及 1080 × 1440 输出规范保持不变。

## 自由创作 1.0.0

- 顶部可切换“标准招募 / 自由创作 / 尺寸适配”；尺寸适配仅占位，未在本版本开发。
- 自由创作仅收集商家名称、主标题、副标题、其他要求、可选产品素材与可选视觉参考图，不包含日期、地点、人数、报名规则、福利等结构化活动字段。
- 支持“AI 自由创意”和“视觉参考创作”；前者允许无图或可选产品图，后者要求至少一张标记为风格参考的图片，只迁移视觉语言，不复制参考图文字、产品、Logo，也不强制复刻构图。
- 主标题必填，主标题与可选副标题均要求原文保留；未提供的营销事实不得编造。
- 继续复用中央创意、上下背景扩展、Logo 信息条、本地品牌合成及 1080 × 1440 输出。
- AI 标题建议预留到 V1.1，本版本未开发。

v1.2.1 在本地品牌合成阶段新增商家 Logo 横版/竖版模板自动选择；AI 创意生成与背景扩展 Prompt 仍为 v5.2，没有变化。

## v1.2 核心优化：上下品牌安全区域

v1.2 的主要更新是重构海报上下品牌安全区域：先在最终画布的真实可用范围内完成中央创意，再单独扩展上下环境背景，降低标题、产品、活动信息等核心内容被品牌信息条遮挡，以及扩展区出现多余文字、Logo 或产品元素的风险。

- 顶部保留 160 px、底部保留 125 px，中央创意固定落在 `y=160–1314`。
- 中央图归一为 1080 × 1215 后，裁去上下各 30 px 的纯背景缓冲，再以原比例放入安全区域，不拉伸、不重排活动内容。
- 第二次图片调用只负责补全上下连续环境背景，明确禁止新增文字、产品、Logo、信息卡或活动元素。
- 中央像素变化率与上下连接行差异会被记录，用于辅助识别中央重绘和明显接缝；这些机械指标不能替代人工视觉验收。

## Prompt v5.2 生成流程

1. 使用 Sunburst 1K 生成一张 8:9 中央完整创意。
2. 裁去中央图上下各 30 px 的纯背景缓冲，得到 1080 × 1155 内容。
3. 将中央内容原比例放入最终画布的 `y=160–1314`。
4. 再调用一次 Sunburst 1K，只扩展顶部和底部的连续环境背景。
5. 本地合成饭团 Logo、真实商家 Logo、底部信息条和商家名称。
6. 执行尺寸、中央像素变化与固定品牌模板检查。

每张最终海报调用 2 次 1K 图片 API，预计 12 credits。生成前必须由用户确认费用；工具不会自动付费重试。

## 输入

- 1–9 张 JPG、PNG 或 WebP 素材。
- 每张素材标记为“真实产品”或“风格参考”。
- 商家 Logo 单独上传，不发送给图片模型重绘。
- 商家名称、招募类型、标题、人数、时间、地址、体验内容和报名规则。
- 可选择“饭团＋商家联名”或“仅饭团”品牌模式。

活动时间、完整地址和报名规则会组织在中央创意底部的同一个三行信息框中。未提供的业务事实不得自动补造。

## 本地启动

macOS 可双击：

```text
启动饭团小红书海报工作台.command
```

或在终端运行：

```bash
python3 -m pip install -r requirements.txt
python3 server.py
```

打开 [http://127.0.0.1:8788](http://127.0.0.1:8788)，通过右上角按钮配置 KIE API Key。Key 默认只保存在当前服务进程内存中。

## 验证边界

- 最终文件固定为 1080 × 1440 PNG。
- 机械检查覆盖尺寸、中央区域变化代理指标和固定模板像素。
- 图片模型第二次调用仍属于生成式图生图，中央像素是否完全保持由指标记录，但不能视为绝对保证。
- 机械验证通过不等于文案、产品真实性和整体视觉已经人工验收。
- 任何重新生成或付费修正都需要再次确认费用。

## Git 与安全

- `.env`、`data/jobs/`、上传素材、生成结果和缓存不会进入 Git。
- 不要把真实 API Key 提交到仓库。
- 生产运行需要随项目提供的品牌 SVG/PNG、饭团 lockup 和指定字体。
- 上传公开仓库前，应确认品牌资产与字体的分发授权。
