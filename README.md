# 饭团小红书招募海报工作台 v1.2

本地运行的饭团小红书招募海报生成工具。用户上传真实产品素材、商家 Logo 并填写活动信息后，工作台通过 KIE 完成中央创意与上下背景扩展，再在本地确定性合成饭团品牌信息条，输出一张 1080 × 1440 PNG。

当前产品版本为 **1.2.0**，生成 Prompt 与管线版本为 **v5.2**。

## Prompt v5.2 生成流程

1. 使用 Sunburst 1K 生成一张 8:9 中央完整创意。
2. 裁去中央图上下各 30 px 的纯背景缓冲，得到 1080 × 1155 内容。
3. 将中央内容原比例放入最终画布的 `y=160–1314`。
4. 再调用一次 Sunburst 1K，只扩展顶部和底部的连续环境背景。
5. 本地合成饭团 Logo、真实商家 Logo、底部信息条和商家名称。
6. 执行尺寸、中央像素变化与固定品牌模板检查。

每张最终海报调用 2 次 1K 图片 API，预计 12 credits。生成前必须由用户确认费用；工具不会自动付费重试。

## 输入

- 1–9 张 JPG、PNG 或 WebP 素材。
- 每张素材标记为“真实产品”或“风格参考”。
- 商家 Logo 单独上传，不发送给图片模型重绘。
- 商家名称、招募类型、标题、人数、时间、地址、体验内容和报名规则。
- 可选择“饭团＋商家联名”或“仅饭团”品牌模式。

活动时间、完整地址和报名规则会组织在中央创意底部的同一个三行信息框中。未提供的业务事实不得自动补造。

## 本地启动

macOS 可双击：

```text
启动饭团小红书海报工作台.command
```

或在终端运行：

```bash
python3 -m pip install -r requirements.txt
python3 server.py
```

打开 [http://127.0.0.1:8788](http://127.0.0.1:8788)，通过右上角按钮配置 KIE API Key。Key 默认只保存在当前服务进程内存中。

## 项目结构

```text
app/static/            前端表单与预览
pipeline/v52.py        v5.2 中央创意与背景扩展管线
skill/assets/          正式品牌模板、字体与 Logo 资产
skill/scripts/         确定性品牌合成和机械验证
tests/                 v5.2 管线测试
server.py              本地 API、任务与 KIE 接入
```

## 验证边界

- 最终文件固定为 1080 × 1440 PNG。
- 机械检查覆盖尺寸、中央区域变化代理指标和固定模板像素。
- 图片模型第二次调用仍属于生成式图生图，中央像素是否完全保持由指标记录，但不能视为绝对保证。
- 机械验证通过不等于文案、产品真实性和整体视觉已经人工验收。
- 任何重新生成或付费修正都需要再次确认费用。

## Git 与安全

- `.env`、`data/jobs/`、上传素材、生成结果和缓存不会进入 Git。
- 不要把真实 API Key 提交到仓库。
- 生产运行需要随项目提供的品牌 SVG/PNG、饭团 lockup 和指定字体。
- 上传公开仓库前，应确认品牌资产与字体的分发授权。
